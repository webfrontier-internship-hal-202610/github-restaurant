## 🐧 Bashの基礎
- **プロンプト**: ユーザーからの入力を促す状態 `$`や`#`
- **Tab補完**: コマンドの一部を入力して`Tab`を押すと補完
- **履歴検索**: `Ctrl+R`で過去のコマンドを検索
- **ジョブ制御**: `Ctrl+C`で削除(kill)、`Ctrl+Z`で停止、`bg`で背景実行、`fg`で再開
- **リダイレクト**: `<`で入力をファイルから、`>`で出力をファイルへ、`|`でパイプライン

## 📁 ファイルシステム
| コマンド | 説明 | 例 |
|---------|------|-----|
| `ls` | ディレクトリ内容表示 | `ls -la` |
| `cd` | ディレクトリ移動 | `cd /home/user` |
| `pwd` | 現在のディレクトリ表示 | `pwd` |
| `mkdir` | ディレクトリ作成 | `mkdir new_dir` |
| `rm` | ファイル/ディレクトリ削除 | `rm -rf old_dir` |
| `cp` | コピー | `cp file1 file2` |
| `mv` | 移動/名前変更 | `mv old new` |

## 📝 ファイル操作
| コマンド | 説明 | 例 |
|---------|------|-----|
| `cat` | ファイル内容表示 | `cat file.txt` |
| `less` | ページ単位で表示 | `less large_file` |
| `grep` | パターン検索 | `grep "pattern" file` |
| `head` | 先頭部分表示 | `head -n 10 file` |
| `tail` | 末尾部分表示 | `tail -f log_file` |

## 🔧 システム＆ネットワーク
